## Work deliberately left outside this completed slice

These are substantive remaining requirements, not inferred passes:

- **Spec 003 successor corpus/tooling:** A0208, A0311, A0312, A0411 and A0412 call for wider vectors,
  richer run evidence, or a successor archive/bundle format. Current frozen tests do not establish
  those extensions. A0309 is conditional on adding an implementation CI expected-failure baseline;
  no such suppression layer was added.
- **Spec 003 independence and reproducibility:** A0413, A1001–1007/A1009, A1106 and the M2 tasks need
  the stated independently maintained implementation/disagreement evidence. A1202, A1204 and A1208
  require a clean archive and exact matching material identities. This dirty-tree wheel replay does
  not close them. A1201 remains bounded by its stronger independent/type gate requirements even
  though the current repository's composite check passes.
- **Specs 004 and 005:** implementation proposals and real evidence must stay distinct. Hiring
  qualified reviewers or obtaining an authorized external sandbox/enterprise dataset are concrete
  prerequisites for their stronger claims. An `OutcomeCertificate` JSON object is not proof that the
  outcome happened.
- **Specs 006 and 007 future work:** any governed learning or runtime effect profile needs an explicit
  admission and observation contract before execution. No second runtime, self-authorization path,
  or automatic promotion is added just to make a proposal's checkbox count zero.

The next useful expansion is one evidence-backed external integration under an exact contract and
scope. Reimplementing internal reference logic or broadening authority would not supply the missing
independent or business evidence.
