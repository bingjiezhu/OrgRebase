# Code of conduct

The GitHub community page reads the workspace-root
[`CODE_OF_CONDUCT.md`](../CODE_OF_CONDUCT.md). This file remains the product-tree copy
of the same policy.

We collaborate with respect, precision, and intellectual honesty. Participants must not
harass, threaten, discriminate against, or expose private information about others.
Technical disagreement is welcome when it focuses on evidence, interfaces, and tradeoffs.

Maintainers may edit or remove abusive, unsafe, spammy, or privacy-violating contributions
and may temporarily or permanently restrict participation. Report conduct concerns through
the repository host's private maintainer contact channel. Maintainers will protect the
privacy and safety of reporters to the extent possible.
