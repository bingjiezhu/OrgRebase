# OrgRebase documentation

Carry enterprise rule changes into execution without letting a candidate authorize itself.

OrgRebase helps quote operations owners keep existing work aligned with changing rules, dates and responsibilities. It uses organizational contracts to identify affected work, generates candidates, performs independent checks, obtains approval from the exact owner, and writes successor versions. Quotes are the runnable reference scenario, not proof that arbitrary enterprise workflows are already supported.

## What the evidence establishes

Candidates, review, approval and application are separate facts. A controlled local or cloud-model demonstration establishes only the exercised path. It does not establish customer deployment, production capacity or willingness to pay. Public historical product records and controlled discounts, taxes and organizational identities must remain distinct.
